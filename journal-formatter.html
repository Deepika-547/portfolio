Journal Formatter

Journal Formatter is an AI writing companion that takes raw, unstructured journal entries and reformats them into clean, well-organized text. It pairs a React + Vite frontend with an Express.js backend that calls the Google Gemini API to do the actual reformatting work.

View on GitHub

Key Features

  • Paste in messy, free-form journal text and get back a cleanly structured version
  • Powered by the Google Gemini API for natural-language reformatting
  • Fast, modern React + Vite frontend for instant feedback
  • Express.js backend handling API requests and environment configuration

Technologies Used

Behind the Scenes

Deploying to Railway involved fixing a TypeScript configuration issue where process.env.PORT needed to be explicitly wrapped with Number() before the server would bind correctly — a small but important production debugging step.
