RedStore — E-Commerce Website

RedStore is a responsive front end for a sports-equipment e-commerce store, built during my Web Development internship at Future Interns. It features a clean storefront layout with a navigation bar (Home, Products, About, Contact, Account) and a tabbed Login / Register panel for user accounts. The project focused on translating a real storefront design into semantic, responsive HTML, CSS and JavaScript.

Visit Live Site

Key Features

  • Responsive storefront layout with a sticky navigation bar and cart icon
  • Tabbed Login / Register panel with form validation
  • Clean, semantic HTML structure with organized, reusable CSS styling
  • Built as part of a structured internship curriculum focused on real-world practices

This project was completed as part of the Future Interns Web Development internship (2025), which focused on applying core front-end concepts to real-world style projects.
