Arjun Store

Arjun Store is a hyperlocal grocery delivery web application that lets customers browse a live product catalog, add items to a cart, and place orders with OTP-verified accounts. I designed, built, and deployed the entire system solo — from the database schema to the production server — and continue to maintain and improve it.

Visit Live Site

Key Features

  • Browse a live, categorized grocery catalog with search
  • Secure sign-up & login with JWT authentication and bcrypt password hashing
  • Email OTP verification and order notifications, sent via Brevo SMTP
  • Order placement and tracking backed by MongoDB & Mongoose
  • Continuous uptime monitoring with UptimeRobot and a submitted sitemap.xml for Google Search Console

Technologies Used

Behind the Scenes

Hosting this project on Render's free tier meant solving real production problems: migrating email delivery from Gmail/SendGrid to Brevo for reliable OTP and order emails, and working around free-tier "sleep" behavior that was blocking Google Search Console verification — fixed with UptimeRobot keeping the service awake.
